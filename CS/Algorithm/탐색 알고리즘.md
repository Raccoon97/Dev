# 탐색 알고리즘이란?
- 데이터 집합에서 **원하는 값을 찾는** 알고리즘이다.
- 탐색의 대상 자료구조에 따라 적절한 알고리즘이 달라진다.

<br><br><br>

# 선형 탐색 (Linear Search)
- 배열의 처음부터 끝까지 **순차적으로** 원하는 값을 찾는다.
- 정렬되어 있지 않은 데이터에 사용할 수 있다.
- 시간 복잡도 : `O(N)`

```swift
func linearSearch(_ arr: [Int], _ target: Int) -> Int? {
    for (index, value) in arr.enumerated() {
        if value == target { return index }
    }
    return nil
}
```

<br><br><br>

# 이진 탐색 (Binary Search)
- **정렬된** 배열에서 사용할 수 있는 탐색 알고리즘.
- 탐색 범위를 **절반씩 줄여나간다.**
- 시간 복잡도 : `O(log N)`

```swift
func binarySearch(_ arr: [Int], _ target: Int) -> Int? {
    var left = 0
    var right = arr.count - 1
    
    while left <= right {
        let mid = (left + right) / 2
        if arr[mid] == target {
            return mid
        } else if arr[mid] < target {
            left = mid + 1
        } else {
            right = mid - 1
        }
    }
    return nil
}
```

### 주의 사항
- 배열이 **정렬되어 있어야** 한다.
- `mid` 계산 시 오버플로를 피하려면 `left + (right - left) / 2` 를 사용하기도 한다.

# DFS (Depth-First Search)
- **깊이 우선 탐색**
- 한 경로로 가능한 한 **깊이 들어가며** 탐색하고, 더 이상 갈 수 없으면 되돌아오는 방식.
- **Stack** 또는 **재귀** 로 구현한다.
- 경로의 특성 (Back Tracking), 연결 성분 찾기에 유리하다.

```swift
func dfs(_ graph: [[Int]], _ start: Int) -> [Int] {
    var visited = Array(repeating: false, count: graph.count)
    var result: [Int] = []
    
    func visit(_ node: Int) {
        visited[node] = true
        result.append(node)
        for next in graph[node] {
            if !visited[next] { visit(next) }
        }
    }
    
    visit(start)
    return result
}
```

<br><br><br>

# BFS (Breadth-First Search)
- **너비 우선 탐색**
- 시작 노드에서 가까운 노드부터 **레벨 단위로** 탐색한다.
- **Queue** 로 구현한다.
- **최단 경로** 탐색에 적합하다 (간선 비용이 모두 같을 때).

```swift
func bfs(_ graph: [[Int]], _ start: Int) -> [Int] {
    var visited = Array(repeating: false, count: graph.count)
    var queue = [start]
    var result: [Int] = []
    visited[start] = true
    
    while !queue.isEmpty {
        let node = queue.removeFirst()
        result.append(node)
        for next in graph[node] where !visited[next] {
            visited[next] = true
            queue.append(next)
        }
    }
    return result
}
```

<br><br><br>

# DFS vs BFS

| 구분 | DFS | BFS |
|---|---|---|
| **자료구조** | Stack / 재귀 | Queue |
| **탐색 방식** | 깊이 우선 | 너비 우선 |
| **최단 경로** | 보장하지 않음 | 보장함 (가중치 동일 시) |
| **메모리** | 상대적으로 적게 사용 | 상대적으로 많이 사용 |
| **활용** | Back Tracking, 경로 탐색 | 최단 경로, 레벨 탐색 |

# 면접 예상 질문
- **Q. 이진 탐색의 조건은 무엇인가요?**
  - 배열이 **정렬되어 있어야** 합니다. 정렬되지 않은 배열에서는 절반씩 탐색 범위를 줄이는 논리가 성립하지 않아 사용할 수 없습니다.

- **Q. DFS 와 BFS 중 최단 경로에는 어떤 것이 적합한가요?**
  - **BFS** 가 최단 경로 탐색에 적합합니다. BFS 는 시작 노드로부터 가까운 노드부터 방문하므로, 가중치가 모두 같다면 처음 도달한 경로가 최단 경로가 됩니다. DFS 는 깊이 우선이므로 최단 경로를 보장하지 않습니다.

- **Q. DFS 는 어떻게 구현하나요?**
  - 일반적으로 **재귀 함수** 나 **Stack** 으로 구현합니다. 재귀는 구현이 간단하지만 입력이 크면 Stack Overflow 가 발생할 수 있어, 실무에서는 명시적인 Stack 을 사용하기도 합니다.

- **Q. 가중치가 있는 그래프에서 최단 경로를 구하려면?**
  - BFS 는 가중치가 동일할 때만 최단 경로를 보장합니다. 가중치가 다를 때는 **다익스트라 (Dijkstra)**, **벨만-포드 (Bellman-Ford)**, **플로이드-워셜 (Floyd-Warshall)** 같은 알고리즘을 사용합니다.

- **Q. 이진 탐색의 변형에는 어떤 것들이 있나요?**
  - **Lower Bound** (해당 값 이상이 처음 나오는 위치), **Upper Bound** (해당 값을 초과하는 값이 처음 나오는 위치), **Parametric Search** (정답을 이분 탐색으로 찾는 기법) 등이 있습니다. 특히 Parametric Search 는 최적화 문제를 결정 문제로 변환해 푸는 방식으로 자주 사용됩니다.
