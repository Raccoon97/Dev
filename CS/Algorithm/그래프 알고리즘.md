# 그래프 알고리즘 개요
- 그래프는 **정점(Vertex)** 과 **간선(Edge)** 으로 이루어진 자료구조이다.
- 기본적인 탐색 알고리즘인 **DFS / BFS** 를 기반으로, 다양한 문제를 해결할 수 있는 알고리즘이 있다.
- 대표적인 문제 : 최단 경로, 최소 신장 트리, 위상 정렬, 연결 성분 등

<br><br><br>

# 최단 경로 (Shortest Path)
- 한 정점에서 다른 정점으로 가는 **가장 짧은 경로** 를 찾는 문제.

### 상황별 최적 알고리즘

| 상황 | 알고리즘 | 시간 복잡도 |
|---|---|---|
| 가중치 없음 | BFS | O(V + E) |
| 양의 가중치, 단일 출발지 | Dijkstra | O((V + E) log V) |
| 음의 가중치 포함, 단일 출발지 | Bellman-Ford | O(VE) |
| 모든 쌍 최단 경로 | Floyd-Warshall | O(V³) |

<br><br><br>

# Dijkstra 알고리즘
- **단일 출발지 최단 경로** 알고리즘.
- **양의 가중치** 그래프에서만 사용 가능.
- **Greedy** 기반으로, 매 단계에서 가장 가까운 미방문 노드를 선택한다.

### 동작 과정
1. 출발 노드의 거리를 0, 나머지를 무한대로 초기화.
2. 방문하지 않은 노드 중 **가장 가까운 노드** 를 선택.
3. 해당 노드를 경유해 각 인접 노드까지의 거리를 갱신 (**Relaxation**).
4. 모든 노드를 방문할 때까지 2-3 반복.

### Priority Queue 기반 구현

```swift
func dijkstra(_ graph: [[(node: Int, weight: Int)]], _ start: Int) -> [Int] {
    var dist = [Int](repeating: Int.max, count: graph.count)
    dist[start] = 0
    
    // (거리, 노드) 가 작은 순으로 꺼내는 Min Heap 이 이상적
    var pq: [(dist: Int, node: Int)] = [(0, start)]
    
    while !pq.isEmpty {
        // 실무에서는 Heap 을 사용해야 O((V + E) log V) 보장
        pq.sort { $0.dist < $1.dist }
        let current = pq.removeFirst()
        
        if current.dist > dist[current.node] { continue }
        
        for edge in graph[current.node] {
            let newDist = dist[current.node] + edge.weight
            if newDist < dist[edge.node] {
                dist[edge.node] = newDist
                pq.append((newDist, edge.node))
            }
        }
    }
    return dist
}
```

### 한계
- **음의 가중치** 간선이 있으면 작동하지 않는다.

# Bellman-Ford 알고리즘
- **단일 출발지 최단 경로** 알고리즘.
- **음의 가중치** 를 허용한다.
- **음수 사이클** 을 감지할 수 있다.
- 시간 복잡도 : `O(VE)` (Dijkstra 보다 느림)

### 동작 과정
1. 출발 노드의 거리를 0, 나머지를 무한대로 초기화.
2. **모든 간선을 V-1 번 반복** 하며 거리를 갱신.
3. V 번째 반복에서도 갱신이 일어나면 **음수 사이클 존재**.

<br><br><br>

# Floyd-Warshall 알고리즘
- **모든 쌍의 최단 경로** 를 구한다.
- **DP** 기반이며 3 중 반복문으로 구현한다.
- 시간 복잡도 : `O(V³)` / 공간 : `O(V²)`

```swift
func floydWarshall(_ dist: inout [[Int]]) {
    let n = dist.count
    for k in 0..<n {
        for i in 0..<n {
            for j in 0..<n {
                if dist[i][k] != Int.max && dist[k][j] != Int.max {
                    dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])
                }
            }
        }
    }
}
```

- **점화식** : `dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])`
- 즉, i → j 로 가는 경로에 k 를 거치는 경로가 더 짧으면 갱신.

# 최소 신장 트리 (MST)
- **Minimum Spanning Tree**
- 그래프의 모든 정점을 연결하는 **사이클이 없는** 부분 그래프 중, **간선 가중치의 합이 최소** 인 것.
- 정점 V 개, 간선 V-1 개.

### Kruskal 알고리즘
- **간선** 을 가중치 순으로 정렬하고, **사이클이 생기지 않는 한** 작은 것부터 선택한다.
- **Union-Find** 로 사이클 여부를 확인한다.
- 시간 복잡도 : `O(E log E)`

```swift
struct Edge { let u, v, weight: Int }

func kruskal(_ n: Int, _ edges: [Edge]) -> Int {
    let sortedEdges = edges.sorted { $0.weight < $1.weight }
    var parent = Array(0..<n)
    
    func find(_ x: Int) -> Int {
        if parent[x] == x { return x }
        parent[x] = find(parent[x])
        return parent[x]
    }
    
    func union(_ a: Int, _ b: Int) -> Bool {
        let rootA = find(a), rootB = find(b)
        if rootA == rootB { return false }
        parent[rootA] = rootB
        return true
    }
    
    var total = 0
    for edge in sortedEdges where union(edge.u, edge.v) {
        total += edge.weight
    }
    return total
}
```

### Prim 알고리즘
- **정점** 기준으로 접근한다.
- 시작 정점에서 출발해, 현재 트리에 연결된 간선 중 **가장 작은 것** 을 추가한다.
- Priority Queue 로 구현하면 `O(E log V)`.

# Union-Find (Disjoint Set)
- **서로소 집합** 을 표현하는 자료구조.
- 두 가지 연산을 빠르게 지원한다 :
  - **Find** : 어떤 원소가 속한 집합을 찾는다.
  - **Union** : 두 집합을 하나로 합친다.
- **Path Compression** 과 **Union by Rank** 를 적용하면 거의 상수 시간 `O(α(N))` 에 동작한다.
- MST 의 Kruskal, 사이클 판별 등에 사용된다.

```swift
class UnionFind {
    var parent: [Int]
    var rank: [Int]
    
    init(_ n: Int) {
        parent = Array(0..<n)
        rank = Array(repeating: 0, count: n)
    }
    
    func find(_ x: Int) -> Int {
        if parent[x] != x {
            parent[x] = find(parent[x])  // Path Compression
        }
        return parent[x]
    }
    
    func union(_ a: Int, _ b: Int) {
        let rootA = find(a), rootB = find(b)
        if rootA == rootB { return }
        // Union by Rank
        if rank[rootA] < rank[rootB] {
            parent[rootA] = rootB
        } else if rank[rootA] > rank[rootB] {
            parent[rootB] = rootA
        } else {
            parent[rootB] = rootA
            rank[rootA] += 1
        }
    }
}
```

# Topological Sort (위상 정렬)
- **DAG (Directed Acyclic Graph)** 에서 정점들의 **선후 관계를 만족하는 순서** 를 정렬한다.
- 예 : 작업 스케줄링, 컴파일 의존성 해결, 선수 과목 순서.
- 사이클이 있으면 위상 정렬이 불가능하다.

### Kahn 알고리즘 (BFS 기반)
1. **진입 차수 (Indegree)** 가 0 인 노드를 Queue 에 넣는다.
2. Queue 에서 노드를 꺼내 결과에 추가하고, 해당 노드와 연결된 간선을 제거한다.
3. 간선 제거로 인해 진입 차수가 0 이 된 노드를 Queue 에 넣는다.
4. Queue 가 빌 때까지 반복.

```swift
func topologicalSort(_ graph: [[Int]], _ n: Int) -> [Int] {
    var indegree = [Int](repeating: 0, count: n)
    for u in 0..<n {
        for v in graph[u] { indegree[v] += 1 }
    }
    
    var queue = (0..<n).filter { indegree[$0] == 0 }
    var result: [Int] = []
    
    while !queue.isEmpty {
        let current = queue.removeFirst()
        result.append(current)
        for next in graph[current] {
            indegree[next] -= 1
            if indegree[next] == 0 { queue.append(next) }
        }
    }
    return result
}
```

# 면접 예상 질문
- **Q. Dijkstra 와 Bellman-Ford 의 차이는?**
  - Dijkstra 는 **양의 가중치** 만 다룰 수 있고 Greedy 기반으로 빠릅니다 `O((V + E) log V)`. Bellman-Ford 는 **음의 가중치** 를 허용하고 **음수 사이클 감지** 도 할 수 있지만 `O(VE)` 로 느립니다. 양의 가중치만 있다면 Dijkstra 를 선호합니다.

- **Q. Dijkstra 에서 Priority Queue 를 왜 사용하나요?**
  - 매 단계에서 **가장 거리가 가까운 미방문 노드** 를 선택해야 하는데, 단순 배열로 찾으면 `O(V)` 가 걸려 전체 복잡도가 `O(V²)` 이 됩니다. **Min Heap (Priority Queue)** 을 사용하면 `O(log V)` 에 꺼낼 수 있어 전체 복잡도가 `O((V + E) log V)` 로 개선됩니다.

- **Q. MST 의 Kruskal 과 Prim 중 어떤 것이 더 좋나요?**
  - 그래프의 **간선이 희소(Sparse)** 할 때는 Kruskal, **밀집(Dense)** 할 때는 Prim 이 효율적입니다. Kruskal 은 간선을 기준으로 정렬하므로 간선 수에 민감하고, Prim 은 정점을 기준으로 확장하므로 정점 수에 민감합니다.

- **Q. Union-Find 의 경로 압축(Path Compression) 이란?**
  - `find` 연산을 할 때 **방문한 모든 노드를 루트에 직접 연결** 하는 최적화입니다. 이를 통해 트리의 깊이가 얕아져 이후의 `find` 가 거의 상수 시간에 동작하게 됩니다. Union by Rank 와 함께 사용하면 `O(α(N))` 에 가깝습니다.

- **Q. 위상 정렬은 어떤 상황에서 사용하나요?**
  - 작업들 사이에 **선후 관계** 가 있을 때 사용합니다. 예를 들어 선수 과목이 있는 수강 순서 결정, 빌드 도구의 의존성 순서 (Make, Gradle), 패키지 매니저의 의존성 해결 등이 대표적인 예시입니다.
