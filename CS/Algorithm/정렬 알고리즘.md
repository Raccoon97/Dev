# 정렬 알고리즘이란?
- 데이터를 **오름차순** 또는 **내림차순** 등 일정한 기준에 따라 재배치하는 알고리즘이다.
- 정렬은 **탐색을 빠르게 하기 위한** 전처리로 자주 사용된다.
- **Stable (안정 정렬)** : 동일한 값의 원소가 정렬 후에도 기존의 상대 순서를 유지하는 정렬
- **In-place (제자리 정렬)** : 추가 메모리를 거의 사용하지 않는 정렬

<br><br><br>

# Bubble Sort
- 인접한 두 원소를 비교해 순서가 맞지 않으면 교환한다.
- 한 번의 Pass 마다 가장 큰 값이 맨 뒤로 이동한다.
- 시간 복잡도 : `O(N²)` / 공간 : `O(1)` / Stable : O

```swift
func bubbleSort(_ arr: inout [Int]) {
    let n = arr.count
    for i in 0..<n {
        for j in 0..<(n - i - 1) {
            if arr[j] > arr[j + 1] {
                arr.swapAt(j, j + 1)
            }
        }
    }
}
```

<br><br><br>

# Selection Sort
- 매번 **최솟값을 찾아** 맨 앞과 교환한다.
- 시간 복잡도 : `O(N²)` / 공간 : `O(1)` / Stable : X

```swift
func selectionSort(_ arr: inout [Int]) {
    let n = arr.count
    for i in 0..<n {
        var minIdx = i
        for j in (i + 1)..<n {
            if arr[j] < arr[minIdx] { minIdx = j }
        }
        arr.swapAt(i, minIdx)
    }
}
```

# Insertion Sort
- 정렬된 부분 배열에 새 원소를 **적절한 위치에 삽입** 한다.
- **거의 정렬된 배열에서는 매우 빠르다** `O(N)`.
- 시간 복잡도 : `O(N²)` (최악) / 공간 : `O(1)` / Stable : O

```swift
func insertionSort(_ arr: inout [Int]) {
    for i in 1..<arr.count {
        let key = arr[i]
        var j = i - 1
        while j >= 0 && arr[j] > key {
            arr[j + 1] = arr[j]
            j -= 1
        }
        arr[j + 1] = key
    }
}
```

# Merge Sort
- **분할 정복 (Divide and Conquer)** 기반의 정렬.
- 배열을 반으로 나누고, 각각을 정렬한 후 **병합** 한다.
- 시간 복잡도 : `O(N log N)` (항상) / 공간 : `O(N)` / Stable : O

```swift
func mergeSort(_ arr: [Int]) -> [Int] {
    guard arr.count > 1 else { return arr }
    let mid = arr.count / 2
    let left = mergeSort(Array(arr[..<mid]))
    let right = mergeSort(Array(arr[mid...]))
    return merge(left, right)
}

func merge(_ left: [Int], _ right: [Int]) -> [Int] {
    var result: [Int] = []
    var i = 0, j = 0
    while i < left.count && j < right.count {
        if left[i] <= right[j] {
            result.append(left[i]); i += 1
        } else {
            result.append(right[j]); j += 1
        }
    }
    result.append(contentsOf: left[i...])
    result.append(contentsOf: right[j...])
    return result
}
```

# Quick Sort
- **분할 정복** 기반의 정렬.
- **Pivot** 을 기준으로 작은 값은 왼쪽, 큰 값은 오른쪽에 배치하고 재귀적으로 정렬한다.
- 시간 복잡도 : `O(N log N)` (평균), `O(N²)` (최악) / 공간 : `O(log N)` / Stable : X
- 평균적으로 가장 빠른 정렬로 알려져 있다.

```swift
func quickSort(_ arr: [Int]) -> [Int] {
    guard arr.count > 1 else { return arr }
    let pivot = arr[arr.count / 2]
    let less = arr.filter { $0 < pivot }
    let equal = arr.filter { $0 == pivot }
    let greater = arr.filter { $0 > pivot }
    return quickSort(less) + equal + quickSort(greater)
}
```

- 최악의 경우 : 이미 정렬된 배열에서 pivot 을 끝 값으로 선택할 때 `O(N²)`.
- 이를 피하기 위해 **Randomized Pivot**, **Median of Three** 등을 사용한다.

<br><br><br>

# Heap Sort
- **Max Heap (또는 Min Heap)** 을 이용한 정렬.
- 배열을 Heap 으로 만든 후, Root(최댓값) 를 맨 뒤로 보내는 과정을 반복한다.
- 시간 복잡도 : `O(N log N)` (항상) / 공간 : `O(1)` / Stable : X

# 정렬 알고리즘 비교

| 알고리즘 | 평균 | 최선 | 최악 | 공간 | Stable | 제자리 |
|---|---|---|---|---|---|---|
| **Bubble Sort** | O(N²) | O(N) | O(N²) | O(1) | O | O |
| **Selection Sort** | O(N²) | O(N²) | O(N²) | O(1) | X | O |
| **Insertion Sort** | O(N²) | O(N) | O(N²) | O(1) | O | O |
| **Merge Sort** | O(N log N) | O(N log N) | O(N log N) | O(N) | O | X |
| **Quick Sort** | O(N log N) | O(N log N) | O(N²) | O(log N) | X | O |
| **Heap Sort** | O(N log N) | O(N log N) | O(N log N) | O(1) | X | O |

### Swift 의 sort
- Swift 의 `sort()` / `sorted()` 는 **Introsort** 를 사용한다.
- Introsort = Quick Sort + Heap Sort + Insertion Sort 의 조합으로, 빠른 평균 성능과 최악 `O(N log N)` 을 보장한다.
- Swift 5 부터는 정렬 결과가 **Stable** 하도록 보장한다.

# 면접 예상 질문
- **Q. Quick Sort 와 Merge Sort 의 차이는?**
  - 둘 다 분할 정복 기반이지만, Quick Sort 는 **Pivot 기준 분할 후 정렬** 하고 Merge Sort 는 **분할 후 병합** 합니다. Quick Sort 는 평균적으로 더 빠르고 제자리 정렬이지만 최악이 O(N²) 이고, Merge Sort 는 항상 O(N log N) 이지만 O(N) 의 추가 공간이 필요합니다.

- **Q. Quick Sort 의 최악의 경우는 언제인가요?**
  - Pivot 을 **이미 정렬된 배열의 맨 끝 값** 으로 선택할 때, 분할이 `0 : N-1` 로 극단적으로 불균형해져 O(N²) 이 됩니다. 이를 방지하기 위해 Randomized Pivot 이나 Median of Three 방식으로 Pivot 을 선택합니다.

- **Q. 안정 정렬(Stable Sort) 은 왜 중요한가요?**
  - 동일한 키를 가진 원소들의 상대적인 순서가 유지되어야 할 때 중요합니다. 예를 들어 **이름순으로 정렬 후 점수순으로 다시 정렬** 할 때 안정 정렬이어야 같은 점수의 학생들이 이름순으로 유지됩니다.

- **Q. 실무에서 어떤 정렬 알고리즘을 사용하나요?**
  - 대부분의 언어는 **Hybrid 정렬** 을 사용합니다. 예를 들어 Swift 는 Introsort, Python 과 Java 는 Timsort 를 사용합니다. 이들은 데이터의 특성에 따라 내부적으로 Insertion Sort, Merge Sort, Quick Sort, Heap Sort 를 조합해 사용합니다.

- **Q. 거의 정렬된 데이터에 가장 적합한 정렬은?**
  - **Insertion Sort** 가 가장 적합합니다. 이미 정렬된 배열에서는 O(N) 에 가까운 성능을 보입니다. 그래서 작은 배열이나 거의 정렬된 부분 배열에서는 O(N log N) 알고리즘보다 더 빠를 수 있고, 실무에서도 Hybrid 정렬의 일부로 사용됩니다.
