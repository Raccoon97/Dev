# 함수형 프로그래밍이란?
- **Functional Programming (FP)** 은 프로그래밍 패러다임 중 하나로, **함수를 1 급 객체(First-class Citizen)** 로 취급해 프로그램을 구성한다.
- **부수 효과(Side Effect)** 를 최소화하고, **불변 데이터** 와 **순수 함수** 를 활용한다.
- 대표 언어 : Haskell, Lisp, Clojure, Erlang, Scala
- Swift, Kotlin, JavaScript 등 현대 언어는 **멀티 패러다임** 으로 함수형 스타일을 지원한다.

<br><br><br>

# 함수형 프로그래밍의 특징

1. **First-class Function** : 함수를 변수에 할당하고, 매개변수로 전달하고, 반환값으로 사용할 수 있다.
2. **Pure Function** : 같은 입력에 대해 항상 같은 출력을 반환하고, 부수 효과가 없다.
3. **Immutability** : 데이터는 생성 후 변경되지 않는다.
4. **Higher-order Function** : 함수를 인자로 받거나 함수를 반환하는 함수.
5. **Referential Transparency** : 어떤 표현식을 그 값으로 대체해도 프로그램의 의미가 변하지 않는다.
6. **Lazy Evaluation** : 필요할 때까지 계산을 미룬다.

<br><br><br>

# 순수 함수 (Pure Function)
- 같은 입력에 대해 **항상 같은 결과** 를 반환한다.
- **외부 상태를 변경하지 않는다** (Side Effect 없음).
- 외부 상태에 의존하지 않는다.

### 순수 함수 ✅

```swift
func add(_ a: Int, _ b: Int) -> Int {
    return a + b
}
```

### 비순수 함수 ❌

```swift
var counter = 0
func increment() -> Int {
    counter += 1  // 외부 상태 변경 (Side Effect)
    return counter
}
```

### 장점
- **테스트가 쉽다** (같은 입력 → 같은 출력)
- **병렬 처리에 안전** (Race Condition 없음)
- **추론과 리팩토링이 쉽다**
- **메모이제이션** 이 가능하다

<br><br><br>

# 불변성 (Immutability)
- 한 번 생성된 데이터는 **수정할 수 없다.**
- 데이터 변경이 필요하면 **새로운 데이터를 생성** 한다.

```swift
let numbers = [1, 2, 3]
// numbers.append(4)  // 컴파일 에러 (let 이므로)

// 새로운 배열을 만들어 반환
let newNumbers = numbers + [4]
```

### 장점
- 상태 변경에 의한 버그가 줄어든다.
- 멀티스레드 환경에서 안전하다.
- 이해하기 쉽다.

<br><br><br>

# 고차 함수 (Higher-Order Function)
- **함수를 인자로 받거나, 함수를 반환하는** 함수.
- Swift 의 대표적인 고차 함수 : `map`, `filter`, `reduce`, `flatMap`, `compactMap`, `sorted`

### map
- 컬렉션의 각 원소에 함수를 적용한 **새 배열** 을 반환.

```swift
let numbers = [1, 2, 3, 4]
let squared = numbers.map { $0 * $0 }  // [1, 4, 9, 16]
```

### filter
- 조건을 만족하는 원소만 담은 **새 배열** 을 반환.

```swift
let evens = numbers.filter { $0 % 2 == 0 }  // [2, 4]
```

### reduce
- 컬렉션을 **하나의 값으로 축약** 한다.

```swift
let sum = numbers.reduce(0, +)  // 10
```

### compactMap
- map 결과에서 `nil` 을 제거한다.

```swift
let strings = ["1", "2", "abc", "4"]
let numbers = strings.compactMap { Int($0) }  // [1, 2, 4]
```

### flatMap
- 중첩된 배열을 평탄화한다.

```swift
let nested = [[1, 2], [3, 4]]
let flat = nested.flatMap { $0 }  // [1, 2, 3, 4]
```

### 함수를 반환하는 고차 함수

```swift
func makeAdder(_ x: Int) -> (Int) -> Int {
    return { y in x + y }
}

let add5 = makeAdder(5)
add5(3)  // 8
```

# Swift 의 함수형 프로그래밍
- Swift 는 **Protocol-Oriented + Object-Oriented + Functional** 멀티 패러다임 언어이다.
- 함수형 요소를 자연스럽게 지원한다 :
  - 1 급 함수 (함수를 변수에 할당, 인자로 전달)
  - 고차 함수 (`map`, `filter`, `reduce`, ...)
  - 클로저
  - 불변성 (`let`)
  - 값 타입 (`struct`, `enum`)
  - Optional Chaining
  - `Result` 타입
- **Combine** 프레임워크는 함수형 리액티브 프로그래밍 (FRP) 을 지원한다.

<br><br><br>

# 명령형 vs 선언형 vs 함수형

### 명령형 (Imperative)
- **"어떻게"** 할지를 기술한다.

```swift
var result: [Int] = []
for num in [1, 2, 3, 4] {
    if num % 2 == 0 {
        result.append(num * num)
    }
}
// result = [4, 16]
```

### 선언형 (Declarative) / 함수형

```swift
let result = [1, 2, 3, 4]
    .filter { $0 % 2 == 0 }
    .map { $0 * $0 }
// result = [4, 16]
```

- 함수형은 **"무엇을"** 할지를 선언한다.
- 코드가 간결하고 의도가 명확하다.

# 면접 예상 질문
- **Q. 함수형 프로그래밍의 장점은?**
  - **순수 함수** 와 **불변성** 덕분에 코드를 추론하기 쉽고, 테스트가 간단하며, 멀티스레드 환경에서도 안전합니다. 또한 **선언형** 으로 작성되어 코드가 간결하고 의도가 명확해 유지보수성이 높습니다.

- **Q. 순수 함수란 무엇인가요?**
  - **같은 입력에 대해 항상 같은 출력** 을 반환하고 **부수 효과가 없는** 함수입니다. 외부 상태를 변경하지 않고 외부 상태에 의존하지 않기 때문에, 함수의 동작을 독립적으로 이해하고 테스트할 수 있습니다.

- **Q. Swift 에서 함수형 프로그래밍을 어떻게 활용하나요?**
  - Swift 는 **1 급 함수, 클로저, 고차 함수(map/filter/reduce), 값 타입(struct), Optional, Result** 등 함수형 요소를 기본 지원합니다. 컬렉션 처리에는 고차 함수를 사용해 명령형 반복문 대신 선언형으로 작성하고, Combine 을 사용해 비동기 데이터 스트림을 함수형으로 처리할 수 있습니다.

- **Q. 고차 함수란 무엇이며 예시를 들어주세요.**
  - 함수를 **매개변수로 받거나 반환하는** 함수입니다. Swift 의 `map`, `filter`, `reduce` 가 대표적이며, 예를 들어 `map { $0 * 2 }` 는 변환 함수를 인자로 받아 각 원소에 적용한 새 배열을 반환합니다.

- **Q. OOP 와 FP 는 대립되는 개념인가요?**
  - 아닙니다. 서로 다른 관점의 패러다임일 뿐 대립되지 않습니다. Swift 나 Kotlin 처럼 **두 패러다임을 모두 지원** 하는 언어에서는 상황에 맞게 혼용합니다. 예를 들어 비즈니스 로직은 OOP 로 도메인을 모델링하고, 데이터 변환이나 이벤트 처리는 함수형 스타일로 작성하는 것이 일반적입니다.
